# Vehicle Maintenance Tracker

A Python command-line application for tracking vehicles, mileage,
maintenance, repairs, and service history.

## Project Purpose

This project combines automotive knowledge with software development.
It is designed as a practical introduction to Python, Git, GitHub,
data storage, testing, and application design.

## Current Features

- Add a vehicle
- Record the vehicle year, make, model, and mileage
- View all saved vehicles
- Save data in a JSON file
- Validate user input

## Planned Features

- Add maintenance and repair records
- Update vehicle mileage
- Display complete service history
- Track upcoming maintenance
- Search and filter records
- Add automated tests
- Replace JSON storage with a database
- Build a graphical or web-based interface

## Technologies

- Python
- JSON
- Git
- GitHub
